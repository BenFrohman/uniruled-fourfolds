Lean 4 Formalization
In the Lean 4 architecture, a rank-3 lattice can be modeled as a free \(\mathbb{Z}\)-module isomorphic to \(\mathbb{Z}^{3}\). We formalize its determinant via an embedding map \(\iota: \mathbb{Z}^3 \to \mathbb{R}^3\), computing the determinant of the basis transformation matrix or via the exterior power \(\bigwedge ^{3}L\).
lean
import Mathlib.LinearAlgebra.Determinant
import Mathlib.LinearAlgebra.FreeModule.PID
import Mathlib.LinearAlgebra.Matrix.ToLinearEquiv

/-!
# Formalization of the Determinant for Rank-3 Lattices in Lean 4
-/

open Matrix

/-- A rank-3 lattice over `ℤ` represented as a free module with a symmetric positive definite bilinear form. -/
structure Lattice3 where
  V : Type*
  [inst_add_comm_group : AddCommGroup V]
  [inst_module : Module ℤ V]
  [inst_free : Module.Free ℤ V]
  rank_eq : Module.finrank ℤ V = 3

namespace Lattice3

variable (L : Lattice3)

/-- The basis of the rank-3 lattice indexed by `Fin 3`. -/
noncomputable def basis : Basis (Fin 3) ℤ L.V :=
  Module.Free.chooseBasis ℤ L.V

/-- The determinant of a lattice map given by the determinant of its representation matrix. -/
noncomputable def latticeDet (f : L.V →ₗ[ℤ] L.V) : ℤ :=
  LinearMap.det f

theorem latticeDet_toMatrix (f : L.V →ₗ[ℤ] L.V) :
    L.latticeDet f = Matrix.det (LinearMap.toMatrix L.basis L.basis f) := by
  rfl

end Lattice3

Wall-Crossing Loci Boundary Visualization
In the study of Bridgeland stability conditions on algebraic varieties (such as surfaces, cubic threefolds, or uniruled fourfolds), the wall-crossing loci are semicircular or nested algebraic walls in the upper-half plane \((\beta, \alpha)\) where the stability of an object changes.
The following python visualization script plots a nested series of these stability walls (walls of destabilization) derived from the numerical invariants (rank, Chern characters) of the interacting sheaves.
python
import numpy as np
import matplotlib.pyplot as plt

# Define potential destabilizing subobject invariants [rank, c1, ch2]
# to calculate semicircular walls: (beta - center)^2 + alpha^2 = radius^2
walls = [
    {"label": "Wall A: (1, 0, -1)", "center": -0.5, "radius": 1.2},
    {"label": "Wall B: (2, 1, -2)", "center": 0.2, "radius": 0.8},
    {"label": "Wall C: (1, -1, 0)", "center": -1.0, "radius": 1.5},
    {"label": "Wall D: (3, 2, -1)", "center": 0.5, "radius": 0.5}
]

plt.figure(figsize=(10, 6))

for wall in walls:
    # Generate beta coordinates within the valid radius domain
    beta_vals = np.linspace(wall["center"] - wall["radius"], wall["center"] + wall["radius"], 300)
    # Calculate upper semi-circle alpha values
    alpha_vals = np.sqrt(np.maximum(0, wall["radius"]**2 - (beta_vals - wall["center"])**2))
    
    plt.plot(beta_vals, alpha_vals, label=wall["label"], linewidth=2)
    plt.fill_between(beta_vals, 0, alpha_vals, alpha=0.05)

plt.title("Wall-Crossing Loci Boundaries in the $(\\beta, \\alpha)$ Stability Plane", fontsize=14, fontweight='bold')
plt.xlabel("$\beta$ (Shift Parameter)", fontsize=12)
plt.ylabel("$\alpha$ (Scaling Parameter)", fontsize=12)
plt.xlim(-2.5, 2.5)
plt.ylim(0, 2.2)
plt.grid(True, linestyle='--', alpha=0.6)
plt.legend(loc="upper right", frameon=True)
plt.axvline(x=0, color='black', linewidth=0.8, linestyle=':')
plt.show()
