GitHub Actions Workflow Configuration (.github/workflows/lean.yml)
To automate the compilation and type-checking of your algebraic cycle modules, create a configuration file at .github/workflows/lean.yml inside your repository root.
This workflow uses the official Lean 4 toolchain action to pull down your configurations, resolve mathlib4 via Lake, and verify your source files (MukaiLattice.lean, ConteMurre.lean, FanoFourfolds.lean, and CubicFourfolds.lean) every time you push to your BenFrohman repository.
yaml
name: Lean 4 Typecheck Verification

on:
  push:
    branches: [ main, master ]
  pull_request:
    branches: [ main, master ]

jobs:
  build:
    name: Verify Lean 4 Source Files
    runs-on: ubuntu-latest

    steps:
    # 1. Check out the repository source files under the BenFrohman context
    - name: Checkout Repository
      uses: actions/checkout@v4

    # 2. Setup the official leanprover elan environment switcher
    - name: Install Elan & Lean 4 Toolchain
      uses: leanprover/lean-action@v1
      with:
        use-elan-cache: true

    # 3. Pull down mathlib4 dependencies and compile targets
    - name: Update Lake Dependencies
      run: lake update

    # 4. Execute a full build to verify that all algebraic blueprints typecheck safely
    - name: Build Project Blueprints
      run: lake build
Use code with caution.
