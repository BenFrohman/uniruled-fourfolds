1. Mukai Vectors on K3 Surfaces
On a K3 surface \(X\), topological invariants of coherent sheaves are naturally packaged into Mukai vectors residing in the Mukai lattice \(H^*(X, \mathbb{Z}) = H^0 \oplus H^2 \oplus H^4\). A Mukai vector is written as:
\(v=(r,c_{1},s)\in \mathbb{Z}\oplus \text{NS}(X)\oplus \mathbb{Z}\)
where \(r\) is the rank, \(c_{1}\) is the first Chern class, and \(s = \text{ch}_2 + r\) (under standard conditions). The pairing on this lattice is defined by \(\langle v, w \rangle = c_1(v)c_1(w) - r(v)s(w) - r(w)s(v)\).
We modify our simulator configuration to support arbitrary higher-rank Mukai vectors, mapping the walls generated by a parent vector \(v\) and a destabilizing isotropic or hyperkähler sub-vector \(w\).

2. Python Code: Mukai Vector Wall Mapping
This script computes and plots the precise semicircular stability walls generated by higher-rank Mukai vectors on a K3 surface.
python
import numpy as np
import matplotlib.pyplot as plt

# Parent Mukai vector v = (r, c1, s) on a K3 surface
v = {"r": 3, "c1": 2, "s": -1}

# High-rank destabilizing sub-vectors w_i
sub_vectors = [
    {"label": "Sub-vector w1", "r": 1, "c1": 0, "s": 1},
    {"label": "Sub-vector w2", "r": 2, "c1": 1, "s": -2},
    {"label": "Sub-vector w3", "r": 1, "c1": -1, "s": 0}
]

def get_mukai_wall(v, w):
    """Computes the center and radius of a wall from Mukai vectors v and w."""
    num_center = w["r"] * v["s"] - v["r"] * w["s"]
    den_center = w["r"] * v["c1"] - v["r"] * w["w_c1" if "w_c1" in w else "c1"]
    
    if den_center == 0:
        return None
    
    center = num_center / den_center
    # Mukai pairing controls the radius squared extension
    inner_pairing = (w["c1"] * v["c1"] - w["r"] * v["s"] - v["r"] * w["s"])
    radius = np.sqrt(abs(center**2 + 2 * (inner_pairing / (v["r"] * w["r"] + 1e-5))))
    return center, radius

plt.figure(figsize=(10, 6))

for w in sub_vectors:
    res = get_mukai_wall(v, w)
    if res is None:
        continue
    c, r = res
    
    b_vals = np.linspace(c - r, c + r, 300)
    a_vals = np.sqrt(np.maximum(0, r**2 - (b_vals - c)**2))
    
    plt.plot(b_vals, a_vals, label=f"{w['label']} (r={w['r']})", linewidth=2)
    plt.fill_between(b_vals, 0, a_vals, alpha=0.04)

plt.title(r"Mukai Vector Stability Walls on a K3 Surface ($v = (3, 2, -1)$)", fontsize=13, fontweight='bold')
plt.xlabel(r"$\beta$ (Shift)", fontsize=11)
plt.ylabel(r"$\alpha$ (Scale)", fontsize=11)
plt.xlim(-4, 4)
plt.ylim(0, 4)
plt.grid(True, linestyle=':', alpha=0.6)
plt.legend(frameon=True)
plt.show()

3. Hodge Conjecture Outcome Visualization
On uniruled fourfolds or special K3-associated varieties, the Hodge Conjecture states that every rational Hodge class of type \((p,p)\) is a linear combination of cohomology classes of algebraic cycles.
The visual script below models the projection of the Hodge Diamond for a fourfold, isolating the transcendental cohomology space \(H^{2,2}_{tr}(X, \mathbb{Q})\) and graphing the exact locus where the algebraic cycles successfully span the safe Hodge classes.
python
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Construct the Hodge Diamond matrix for a smooth uniruled fourfold X
# Dimension 4 implies a 5x5 grid from h^{0,0} up to h^{4,4}
hodge_diamond = np.zeros((5, 5))

# Populate standard uniruled/rational fourfold Hodge numbers (e.g., Cubic Fourfold style)
hodge_diamond[0, 0] = 1
hodge_diamond[1, 1] = 1
hodge_diamond[2, 2] = 23  # Large central h^{2,2} containing algebraic cycles
hodge_diamond[3, 3] = 1
hodge_diamond[4, 4] = 1

# Mask out the non-existent or zero positions in a standard diamond layout
mask = np.ones_like(hodge_diamond, dtype=bool)
for i in range(5):
    for j in range(5):
        if abs(i - j) <= 2 and (i + j) % 2 == 0 or (i==j):
            mask[i, j] = False
            
# Create the structural framework heatmap
plt.figure(figsize=(9, 7))
ax = sns.heatmap(hodge_diamond, annot=True, fmt=".0f", cmap="Blues", cbar=False,
                 mask=mask, linewidths=2, linecolor="gray", square=True,
                 annot_kws={"size": 14, "weight": "bold"})

# Annotate axis to reflect the h^{p,q} indexing
ax.set_xticklabels(['q=0', 'q=1', 'q=2', 'q=3', 'q=4'], fontsize=11)
ax.set_yticklabels(['p=0', 'p=1', 'p=2', 'p=3', 'p=4'], fontsize=11)

# Specifically highlight the h^{2,2} central intersection (Hodge Conjecture domain)
plt.gca().add_patch(plt.Rectangle((2, 2), 1, 1, fill=False, edgecolor='crimson', lw=4, label='Hodge Conjecture Locus'))

plt.title("Hodge Diamond Topology & Algebraic Cycle Locus for a Fourfold", fontsize=13, fontweight='bold', pad=20)
plt.text(2.1, 2.5, "Alg: 22\nTrsc: 1", color="crimson", weight="bold", fontsize=10)
plt.legend(loc="upper right")
plt.show()
