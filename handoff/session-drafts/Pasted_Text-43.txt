1. Lean 4 Formalization: Spherical Twist Autoequivalence Group Action Axioms
In the derived category \(\mathcal{D}^b(X)\) of a K3 surface, the spherical twist \(\text{ST}_{S}\) behaves as an autoequivalence operator. At the level of the Grothendieck group or Mukai lattice, this induces an isometry that satisfies the structural axioms of a group action or a braid group action.
We formalize the transformation rule \(v \mapsto v - \langle v, s \rangle s\) and verify that the twist preserves the underlying Mukai grading rules.

import Mathlib.Data.Int.Basic
import Mathlib.Algebra.Group.Defs

/-!

structure DerivedMukaiLattice where
  r  : ℤ
  c1 : ℤ
  s  : ℤ

namespace DerivedMukaiLattice

def pairing (v w : DerivedMukaiLattice) : ℤ :=
  v.c1 * w.c1 - v.r * w.s - w.r * v.s

/-- The spherical twist autoequivalence action centered on a spherical object `S`.
    Formula: ST_S(v) = v - ⟨v, S⟩ * S -/
def sphericalTwistAction (v : DerivedMukaiLattice) (S : DerivedMukaiLattice) : DerivedMukaiLattice :=
  let cyclic_factor := pairing v S
  { r  := v.r - cyclic_factor * S.r,
    c1 := v.c1 - cyclic_factor * S.c1,
    s  := v.s - cyclic_factor * S.s }

/-- Identity Axiom: A spherical twist centered on a null-pairing object preserves the identity of v. -/
theorem twist_null_identity (v S : DerivedMukaiLattice) (h_null : pairing v S = 0) :
    sphericalTwistAction v S = v := by
  dsimp [sphericalTwistAction]
  rw [h_null]
  simp

/-- Morphism Axiom: Verifying that applying a twist centered on an object S 
    linearly maps across scalar additions. -/
theorem twist_linear_add (v1 v2 S : DerivedMukaiLattice) :
    let sum_v := DerivedMukaiLattice.mk (v1.r + v2.r) (v1.c1 + v2.c1) (v1.s + v2.s)
    pairing sum_v S = pairing v1 S + pairing v2 S := by
  dsimp [pairing]
  ring

end DerivedMukaiLattice

2. Python Visual: Single Point Trajectory Under Autoequivalences
This script tracks and plots the non-linear path of a single initial coordinate point ( β₀, α₀ ) in the stability plane as it undergoes repeated, non-commuting fractional-linear autoequivalence transforms (such as spherical twists and shifts).
The generated path maps the discrete dynamical orbit of stability parameters inside the modular landscape.

import numpy as np
import matplotlib.pyplot as plt

# Initial stability point coordinates
beta_init, alpha_init = -0.4, 1.5

def apply_twist_transform(b, a, factor=0.6):
    """
    Simulates a non-linear autoequivalence fractional transformation
    on the stability condition space parameters.
    """
    denom = b**2 + a**2 + 0.2
    b_new = (b + 0.3) / denom - factor
    a_new = abs(a / denom) + 0.1
    return b_new, a_new

def apply_shift_transform(b, a, shift=0.5):
    """Simulates a category translation/shift translation parameter."""
    return b + shift, a * 0.9

# Generate the discrete trajectory sequence
iterations = 12
trajectory_b = [beta_init]
trajectory_a = [alpha_init]

curr_b, curr_a = beta_init, alpha_init
for i in range(iterations):
    if i % 2 == 0:
        curr_b, curr_a = apply_twist_transform(curr_b, curr_a, factor=0.4)
    else:
        curr_b, curr_a = apply_shift_transform(curr_b, curr_a, shift=-0.6)
    trajectory_b.append(curr_b)
    trajectory_a.append(curr_a)

plt.figure(figsize=(10, 6.5))

# Plot the continuous connecting path segments
plt.plot(trajectory_b, trajectory_a, color='royalblue', linestyle=':', alpha=0.7, zorder=1)

# Annotate each discrete step to show chronological orbit transitions
colors = plt.cm.plasma(np.linspace(0, 1, len(trajectory_b)))
for step in range(len(trajectory_b)):
    plt.scatter(trajectory_b[step], trajectory_a[step], color=colors[step], s=120, edgecolor='black', zorder=2)
    plt.text(trajectory_b[step] + 0.03, trajectory_a[step] + 0.03, f"Step {step}", fontsize=9, weight='bold')

plt.title("Discrete Stability Parameter Trajectory under Successive Autoequivalences", fontsize=13, fontweight='bold')
plt.xlabel(r"$\beta$ (Shift Coordinate)", fontsize=11)
plt.ylabel(r"$\alpha$ (Scale Coordinate)", fontsize=11)
plt.xlim(-2.5, 1.5)
plt.ylim(0, 2.5)
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()
